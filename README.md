# The Lagom License

*Not too much, not too little — just the right amount of freedom.*

An open-source license for software that doesn't try too hard.

## What is Lagom?

**Lagom** (Swedish, adj.) — not too much, not too little. Just right.

Most licenses are either too restrictive or too permissive. The Lagom License finds the balance: you can use, modify, and distribute the software — just credit the author (but not in 40pt bold font), include the license, and keep things sensible.

## The Gist

- **Use it** — but don't power a galactic empire with it
- **Share it** — but don't give it away with a parade
- **Credit the author** — a small acknowledgment is enough
- **Modify it** — but not so much the original author feels inadequate
- **No warranty** — if it breaks, that is unfortunate, but expected

## Usage

Copy the [LICENSE](LICENSE) file into your project. That's it. Don't overthink it.

## Dispute Resolution

Coffee, cinnamon buns, and a calm discussion. Litigation is never lagom.
